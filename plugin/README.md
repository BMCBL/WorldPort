# WorldPort

在《Minecraft》基岩版（Bedrock）与 Java 版之间双向转换世界：方块与方块状态、方块实体
（箱子、告示牌、熔炉……）、实体与完整 NBT、物品与背包、玩家数据、地图、计划刻和
`level.dat`（种子、出生点、时间、游戏规则）。

## 使用

1. 打开「工具 → 世界转换」。
2. 输入、粘贴或浏览选择源世界目录，也可直接粘贴 `level.dat` 文件路径（Java 世界带 `region/` 或 `dimensions/`，基岩版世界带 `db/`）。
3. 自动识别世界名称、实际游戏版本及存档图标（基岩版 `world_icon.jpeg`、Java 版 `icon.png`），输出目录会自动填一个建议路径。检测不扫描区块数据库。
4. 选择方向与目标版本（默认转成另一版本，Java 目标可选 1.20.6 ~ 26.2）。
5. 输出目录应为空或尚未创建。需要时展开「高级选项」调整线程数与 Java 压缩级别。
6. 点「开始转换」。转换期间可以离开本页，任务会继续；回来时进度自动恢复。

## 原生组件

插件由单独授权的原生组件读写存档。

1. 在「工具 → 世界转换」点击「安装并授权」。
2. 插件下载与当前版本和平台匹配的原生组件，BMCBL 校验 SHA-256 后弹出授权窗口。
3. 确认信任该原生组件后授权安装，再选择源存档。拒绝授权时不会加载原生代码。

网络访问仅声明 WorldPort 的官方市场详情、镜像下载路径、GitHub Release 下载路径及 GitHub 资源重定向域名。

## 说明

- 目标版本比源版本旧时会自动剔除目标版本不存在的方块/实体并写入报告，避免损坏存档。
- 非原版（mod/addon）内容在转换时会被剔除并计数。
- 基岩版→Java 会写出可映射的村庄兴趣点。转换报告会记录结构生成区的保留情况。
- 光照不重算，进入游戏后由游戏自己补全。
