# WorldPort

在《Minecraft》基岩版（Bedrock）与 Java 版之间双向转换世界：方块与方块状态、方块实体
（箱子、告示牌、熔炉……）、实体与完整 NBT、物品与背包、玩家数据、地图、计划刻和
`level.dat`（种子、出生点、时间、游戏规则）。

## 使用

1. 打开「工具 → 世界转换」。
2. 选择源世界文件夹（Java 世界带 `level.dat`，基岩版世界带 `db/`）。
3. 点「检测」确认版本、区块数与玩家数；输出目录会自动填一个建议路径。
4. 选择方向与目标版本（默认转成另一版本，Java 目标可选 1.20.6 ~ 26.2）。
5. 需要时展开「高级选项」调整并行线程、压缩级别或覆盖已有目录。
6. 点「开始转换」。转换期间可以离开本页，任务会继续；回来时进度自动恢复。

## 原生组件

Wasm 沙箱没有文件系统权限，实际读写由内置原生组件完成：

1. 在「设置 → 插件」中批准 `worldport_native.dll`。
2. 把该文件的 SHA-256 填到本页「启用原生转换组件」一栏并保存。

之后「浏览 / 检测 / 转换」都通过原生组件执行，不经过 Wasm 边界。

## 说明

- 目标版本比源版本旧时会自动剔除目标版本不存在的方块/实体并写入报告，避免损坏存档。
- 非原版（mod/addon）内容在转换时会被剔除并计数。
- 结构与村庄 POI 不转换（与原版 Chunker 相同的边界），报告里会说明。
- 光照不重算，进入游戏后由游戏自己补全。
